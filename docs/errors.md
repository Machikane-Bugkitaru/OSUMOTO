# LINE 返信とエラーログ

| 発生条件                     | LINE への返信                                                        | 実際のログ文言                                         |
| ---------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------ |
| OpenAI のタイムアウト        | `時間かかって失敗したわ。もっかいたのむで。`                         | `チャット応答に失敗しました`／`画像処理に失敗しました` |
| OpenAI の利用枠不足          | `金なくなったわ。恵んでくれや。`                                     | `チャット応答に失敗しました`／`画像処理に失敗しました` |
| OpenAI の内容制限            | `あかんプロンプトみたいや。他ので試してくれや。`                     | `チャット応答に失敗しました`／`画像処理に失敗しました` |
| その他の OpenAI エラー       | `なんか失敗したわ。もっかいたのむで。`                               | `チャット応答に失敗しました`／`画像処理に失敗しました` |
| 会話の回答が空               | `なんか失敗したわ。もっかいたのむで。`                               | `チャット応答に失敗しました`                           |
| 会話の履歴を確保できない     | `なんか失敗したわ。もっかいたのむで。`                               | `チャット応答に失敗しました`                           |
| 「画伯」の指示がない         | `「画伯」のあとに、ワイに描いてほしい内容を書いてくれや`             | ログなし                                               |
| 準備した画像の指示が空       | `なんか失敗したわ。もっかいたのむで。`                               | `画像処理に失敗しました`                               |
| 画像準備で時間を使い切った   | `なんか失敗したわ。もっかいたのむで。`                               | `画像処理に失敗しました`                               |
| 生成した画像データがない     | `画像生成したけど内容どっかいったわ。もっかいたのむで。`             | `画像処理に失敗しました`                               |
| Google Drive の容量不足      | `おまいら画像生成しすぎて保存でけへんくなったわ。古いの消してくれ。` | `画像処理に失敗しました`                               |
| 画像保存の認証・権限エラー   | `画像生成したけど内容どっかいったわ。もっかいたのむで。`             | `画像処理に失敗しました`                               |
| その他の画像保存失敗         | `画像生成したけど内容どっかいったわ。もっかいたのむで。`             | `画像処理に失敗しました`                               |
| 送信者プロフィールの取得失敗 | 会話の結果を返信                                                     | 例外全体                                               |
| 受信画像を取得できない       | 返信なし                                                             | `受信画像を取得できませんでした`                       |
| 受信画像の保持容量超過       | 返信なし                                                             | `受信画像の保持容量上限により画像データを解放しました` |
| 受信画像の履歴を確保できない | 返信なし                                                             | `Webhook イベントの処理に失敗しました`                 |
| イベントの保持数上限         | 返信なし                                                             | `Webhook イベントの処理に失敗しました`                 |
| その他のイベント処理失敗     | 返信なし                                                             | `Webhook イベントの処理に失敗しました`                 |
| LINE への返信送信失敗        | 追加返信なし                                                         | `Webhook イベントの処理に失敗しました`                 |
| 失敗したイベントの再受信     | 返信なし                                                             | `Webhook イベントの処理に失敗しました`                 |
| 署名が不正                   | 返信なし                                                             | ログなし                                               |
| 受信 JSON が不正             | 返信なし                                                             | ログなし                                               |
| イベントデータの形式不正     | 返信なし                                                             | ログなし                                               |
| リクエスト処理のエラー       | 返信なし                                                             | `Webhook リクエストを処理できませんでした`             |
| 起動時の設定・初期化エラー   | 返信なし                                                             | ログなし                                               |
