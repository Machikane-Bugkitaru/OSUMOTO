# LINE 返信とエラーログ

「返信なし」= 追加通知なし、「ログなし」= アプリの明示ログなし、`{…}` = 動的な値。LINE 欄は内部例外ではなく、送信成功時の文言。

| 発生条件                                                                        | LINE への返信                                                                   | 実際のログ文言                                                                                       |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| OpenAI のタイムアウトをクライアントで正規化した失敗                             | `時間かかって失敗したわ。もっかいたのむで。`                                    | `チャット応答に失敗しました`／`画像処理に失敗しました`（`stage`: `preparation` または `generation`） |
| OpenAI の code が `insufficient_quota`                                          | `金なくなったわ。恵んでくれや。`                                                | `チャット応答に失敗しました`／`画像処理に失敗しました`（`stage`: `preparation` または `generation`） |
| OpenAI の code が `moderation_blocked`                                          | `あかんプロンプトみたいや。他ので試してくれや。`                                | `チャット応答に失敗しました`／`画像処理に失敗しました`（`stage`: `preparation` または `generation`） |
| その他の OpenAI・検索・通信失敗。`rate_limit_exceeded`、認証・権限エラーなど    | `なんか失敗したわ。もっかいたのむで。`                                          | `チャット応答に失敗しました`／`画像処理に失敗しました`（`stage`: `preparation` または `generation`） |
| 会話の空・空白回答、新しいグループの履歴を確保できない                          | `なんか失敗したわ。もっかいたのむで。`                                          | `チャット応答に失敗しました`                                                                         |
| 「画伯」の後の指示が空                                                          | `「画伯」のあとに、ワイに描いてほしい内容を書いてくれや`                        | ログなし                                                                                             |
| 準備したプロンプトが空、または準備後に共有予算 40 秒の残りがない                | `なんか失敗したわ。もっかいたのむで。`                                          | `画像処理に失敗しました`、`stage: preparation`（準備）                                               |
| 生成応答の先頭に base64 画像データがない・空                                    | `画像生成したけど内容どっかいったわ。もっかいたのむで。`                        | `画像処理に失敗しました`、`stage: response`（生成結果）                                              |
| Drive 保存失敗の reason に `storageQuotaExceeded` がある                        | `おまいら画像生成しすぎて保存でけへんくなったわ。古いの消してくれ。`            | `画像処理に失敗しました`、`stage: storage`（保存）                                                   |
| その他の Drive 保存失敗。認証設定不正、権限、レート制限、保存要求の 10 秒超など | `画像生成したけど内容どっかいったわ。もっかいたのむで。`                        | `画像処理に失敗しました`、`stage: storage`（保存）                                                   |
| 送信者プロフィール取得失敗                                                      | 固定文言なし。継続後の `{整形後のモデル回答}`、会話も失敗すれば対応する失敗文言 | `{例外全体}`（固定文言なし）                                                                         |
| 受信画像の取得失敗・非対応形式・空・8 MiB 超・10 秒超、外部由来の画像           | 返信なし。後の質問では取得不能な画像をモデル入力から除外                        | `受信画像を取得できませんでした`                                                                     |
| 画像保持量の上限超過でデータを解放                                              | 返信なし。解放した画像は後のモデル入力から除外                                  | `受信画像の保持容量上限により画像データを解放しました`、`{ releasedImages: 解放枚数 }`               |
| 対象外の入力、正常な画像受信のみ、履歴無効の画像受信                            | 返信なし                                                                        | ログなし（取得失敗・解放・履歴確保失敗は各行のとおり）                                               |
| 画像受信時の履歴確保失敗、重複排除上限、その他の未処理イベント例外              | 返信なし。HTTP 500                                                              | `Webhook イベントの処理に失敗しました`                                                               |
| LINE 返信 API の失敗。整形後の空本文が拒否される場合も含む                      | 返信なし（代替通知なし）。HTTP 500。元の送信の到達有無は判定しない              | `Webhook イベントの処理に失敗しました`                                                               |
| 同じイベント ID の再受信                                                        | 返信なし（重複分の再送なし）。元の結果が成功なら HTTP 200、失敗なら 500         | 成功結果: ログなし。失敗結果: `Webhook イベントの処理に失敗しました`                                 |
| 署名検証失敗                                                                    | 返信なし。HTTP 403                                                              | ログなし                                                                                             |
| SDK の JSON 解析エラー、events が配列でない・要素が null やオブジェクト以外     | 返信なし。HTTP 400                                                              | ログなし                                                                                             |
| イベント集約外の共通リクエストエラーハンドラーに届くその他の例外                | 返信なし。HTTP 500                                                              | `Webhook リクエストを処理できませんでした`（付加情報なし）                                           |
| 起動時の必須設定・履歴上限・SDK 初期化の失敗                                    | 返信なし。受付開始前に停止                                                      | ログなし（未捕捉例外の表示は実行環境に依存）                                                         |
